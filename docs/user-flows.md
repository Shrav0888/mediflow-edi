# User Flows: Medical Records & Follow-Ups

> **Note:** All examples below use fictional sample data only.

## 1. Adding & Searching a Medical Document (Patient or Staff)
1. Navigate to the **Medical Records** page (`RecordsPage.jsx`).
2. Enter a **Document title** (e.g., `Sample Blood Panel Summary`).
3. Choose a **Document type** (e.g., `Prescription`, `Test Result`, `Lab Report`, or `Consultation Note`).
4. Pick a **Document date**.
5. Use the file-selection control to select a sample file.
6. Submit the form to add the sample document to the list.
7. Use the **Search Records** box to filter documents by title, type, or file name.

## 2. Creating & Viewing a Follow-Up (Patient or Staff)
1. Navigate to the **Follow-Ups** page (`FollowUpsPage.jsx`).
2. Enter a sample **Patient name**.
3. Select a **Follow-up date**.
4. Add a **Short note** describing the reason for the follow-up.
5. Select a **Reminder status** (e.g., `Pending`, `Scheduled`, or `Sent`).
6. Submit the form to add the entry to the **Upcoming Follow-Ups** list and review reminder statuses.
